STEP 2: Set Up GitHub Integration (RECOMMENDED - Takes 5 minutes)
═════════════════════════════════════════════════════════════════════════════════

  A. Install ngrok (for public access to Jenkins)
  ───────────────────────────────────────────────
     macOS:   brew install ngrok
     Windows: Download from https://ngrok.com/download
     Linux:   wget https://bin.equinox.io/c/bNyj1mQVY4c/ngrok-v3-stable-linux-amd64.tgz

  B. Create ngrok account & authenticate
  ──────────────────────────────────────
     1. Go to https://ngrok.com and sign up (free)
     2. Get your auth token from https://dashboard.ngrok.com/auth
     3. Run: ngrok config add-authtoken YOUR_TOKEN

  C. Start ngrok tunnel
  ──────────────────────
     ngrok http 8080

     You'll see:
     ┌────────────────────────────────────────┐
     │ Forwarding  https://xxxxx.ngrok.io     │
     │   -> http://localhost:8080             │
     └────────────────────────────────────────┘

     ⚠️  COPY THIS URL (you'll need it)

  D. Set up GitHub webhook
  ────────────────────────
     1. Go to your GitHub repo → Settings → Webhooks
     2. Click "Add webhook"
     3. Fill in:
        Payload URL: https://xxxxx.ngrok.io/github-webhook/
        Content type: application/json
        Events: ✓ Push events
        Active: ✓ (checked)
     4. Click "Add webhook"

  E. Create Jenkins Pipeline Job
  ──────────────────────────────
     1. Go to http://localhost:8080
     2. Click "New Item"
     3. Name: "crop-predictor-pipeline"
     4. Select "Pipeline" → OK
     5. Configure:
        - Definition: "Pipeline script from SCM"
        - SCM: "Git"
        - Repository URL: https://github.com/YOUR_USERNAME/farmer-crop-predictor.git
        - Credentials: (add if private - use GitHub PAT)
        - Branch: */main
        - Script Path: jenkins/Jenkinsfile
        - Build Triggers: ✓ GitHub hook trigger for GITscm polling
     6. Save

  F. Test the automation
  ──────────────────────
     1. Make a test commit:
        echo "Auto-deploy test" >> README.md
        git add README.md
        git commit -m "Test webhook"
        git push origin main

     2. Watch Jenkins automatically build! 🎉
        Go to http://localhost:8080 and watch it trigger

║                         🆘 TROUBLESHOOTING                                     ║
╚════════════════════════════════════════════════════════════════════════════════╝

  Q: Services won't start?
  A: docker-compose down && docker-compose up -d --build

  Q: Lost Jenkins password?
  A: docker exec crop_jenkins cat /var/jenkins_home/secrets/initialAdminPassword

  Q: GitHub webhook not triggering?
  A: 1. Check ngrok is running
     2. Verify webhook delivery in GitHub (Settings → Webhooks → Recent Deliveries)
     3. Verify "GitHub hook trigger" is checked in Jenkins job
     4. Check Jenkins logs: docker-compose logs -f jenkins

  Q: Port 3000/5000/8080 already in use?
  A: Edit docker-compose.yml ports and change to different port
